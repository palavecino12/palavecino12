## 🚀 Proyectos principales

### 🏠 Dooria

Aplicación web de **control de acceso para entornos residenciales mediante reconocimiento facial**, compuesta por dos interfaces:

- **/app:** aplicación Mobile First para residentes, donde pueden registrar y administrar personas, configurar permisos de acceso y visualizar en tiempo real el dispositivo de ingreso.
- **/intercom:** interfaz destinada al dispositivo de acceso, encargada de capturar video, detectar y reconocer rostros y transmitir el estado del reconocimiento a los residentes.

Desarrollé la arquitectura completa del sistema, tanto frontend como backend. Implementé una **API REST con Node.js y Express** utilizando una arquitectura por capas **Repository → Service → Controller**, validación con Zod, manejo centralizado de errores y persistencia en MongoDB.

Integré **face-api.js** para reconocimiento facial, **Socket.IO** para comunicación en tiempo real y **WebRTC** para la transmisión de video entre el intercom y los residentes.

### 🛒 Zapi

Solución de **autoservicio para un kiosco de la facultad**, desarrollada para automatizar el proceso de compra mediante escaneo de productos, control de stock y pago digital.

Participé en un equipo de **7 personas bajo metodología Scrum**, desempeñándome como **Scrum Master** y participando activamente en el desarrollo.

Diseñé e implementé el **backend completo** con Node.js, Express y TypeScript, utilizando **Prisma y MySQL**. Construí una API REST con arquitectura **Repository → Service → Controller**, validación con Zod, manejo centralizado de errores y errores personalizados.

Implementé la gestión de productos, control de stock y procesamiento de ventas. También desarrollé el **checkout con Mercado Pago Checkout Pro**, incluyendo validación de productos y stock, creación de ventas pendientes, webhook, validación de pagos, prevención de duplicados y transacciones de Prisma para garantizar operaciones atómicas.

Diseñé el modelo de ventas mediante **Sale, SaleItem y Payment**, permitiendo conservar el historial de operaciones y sentando las bases para futuras funcionalidades de análisis.

En el frontend participé en el desarrollo con **React y TypeScript**, utilizando Hooks y Context API para el manejo del estado y la gestión del carrito.
